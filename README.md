# ✅ Laravel ToDo App – First of Many

**By: Maharshi Kattel**  
*“Only took me 2 months – but it’s done!”*

A simple and clean **ToDo list application** built using **Laravel** and **Blade templating**. This project helped me understand core Laravel concepts like routing, controllers, models, views, and form handling. It’s a minimal app but a huge step in my Laravel journey.

---

## 🔧 Features

- Create, update, and delete todos
- Mark todos as complete by deletes
- View todos and descriptions
- Simple and clean Blade-powered UI
- Fully functional CRUD operations

---

## 🛠 Tech Stack

- **PHP Laravel**
- **Blade Templating Engine**
- **Bootstrap** for styling
- **XAMPP** for local server
